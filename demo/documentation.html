Pixel 2.4.1 is Colorlib's free news and magazine Blogger theme. This guide covers installation, navigation, feed widgets, ads, comments, and upgrades.

Download the Blogger theme ZIP · Release history · Upgrade guide

1. Install or upgrade

  1. Back up your existing theme using Theme → Customize dropdown → Backup → Download. Keep copies of your Layout gadget settings, menus, and ad code.
  2. Extract the downloaded ZIP and open Pixel-Blogger-Template.xml. Test the theme on a separate Blogger blog first.
  3. In Blogger, open Theme → Edit HTML, replace the entire theme with the XML, and save.
  4. In the theme's mobile settings, select Desktop to use the responsive theme on phones.
  5. Restore your own widget settings and replace the sample labels, links, author details, and advertisements.

Pixel Demo Content.xml is optional sample content, imported through Settings → Manage blog → Import content. It does not install the theme and is not needed when upgrading an established blog.

2. Feed and page-size settings

Use Settings → Site feed → Allow blog feed → Full for complete widget images and excerpts. Leave Post feed redirect URL empty. A disabled or shortened feed can prevent widgets from showing the expected content.

Set Layout → Posts Per Page to a positive whole number, such as 6, and match it to Blogger's Max posts shown on main page setting.

There is one pagination bar. Optional numbers appear inside it only when the feed allows reliable jumps. Duplicate publication dates or shortened pages use native Older/Newer links. If a later numbered request fails, the optional numbers are removed and native links remain. Search results and date archives keep Blogger's native navigation.

3. Logo, colors, and author information

Edit the Header gadget in Layout to upload a logo or show your blog title. Change theme colors through Theme → Customize → Advanced. Set Boxed Layout to true for a constrained desktop wrapper or false for the normal layout.

Replace the sample text in Author Description and update Author Social Links. Keep a readable blog title in Blogger's settings even if you use a logo.

4. Navigation and mega menus

Edit Layout → Main Navigation Menu. Disable automatic sorting and arrange links in their intended order. Home is supplied automatically.

  • Destinations is a top-level link.
  • _Europe nests beneath the preceding top-level item.
  • __Italy nests beneath Europe.
  • _Asia is another child of Destinations.

Only leading underscores create nesting. For a mega menu, use the exact post label as the link name, for example travel, and use [Mega Menu] as the URL. Label matching is case-sensitive. Phones use the generated navigation select.

5. Social profiles

In Top Social Widget, use supported names such as instagram, pinterest, youtube, tiktok, x-twitter, facebook, threads, telegram, whatsapp, linkedin, or rss. Set each URL to your profile and remove unused placeholder links.

6. Featured grid

In Featured Grid Widget, enter this HTML and replace travel with a label used by published posts:

<span data-type="pixelfeatured" data-label="travel"></span>

The homepage grid displays up to three matching posts. Clear the gadget content to disable it.

7. Homepage lists and galleries

Add separate HTML/JavaScript gadgets inside Customized Widgets. These examples display five posts from a label:

<object class="pixel-widget" data-label="travel" data-type="list"></object>
<object class="pixel-widget" data-label="mountain" data-type="gallery"></object>

Use one example per gadget. The gallery supports images and YouTube thumbnails supplied by Blogger's feed. Replace label names exactly; write an ampersand inside an HTML attribute as &amp;.

8. Sidebar and tabs

Add HTML/JavaScript gadgets in the sidebar or Tab [1], Tab [2], and Tab [3]. The gadget title becomes the tab label. Empty tab sections are omitted.

<!-- Recent posts -->
<span class="pixel-recent" data-no="5"></span>
<!-- Recent comments -->
<span class="pixel-cmnt" data-no="5"></span>
<!-- Posts matching a label -->
<span class="pixel-tagswid" data-label="travel" data-no="5"></span>

Tabs support Left/Right arrows, Home/End, Enter, and Space. Use Tab to move into the selected panel.

9. Advertisement slots

Replace the sample image links in Home Advertisement [Full Width], Post Page Advertisement [Top], and Post Page Advertisement [Bottom] with your own ad code. Clear unused slots. Sidebar ads are separate gadgets. The theme provides placements; approval and actual page performance depend on your content and ad service.

10. Comment providers

Set Comments System to [blogger] for native comments. Supported combinations include [blogger][disqus] and [blogger][disqus][facebook]. Use the exact bracket tokens without spaces; their order determines the tabs.

For Disqus, enter your own Disqus Shortname. Optional providers need working service configuration. Native Blogger comments are the simplest starting point.

11. Troubleshooting and support

  • No featured posts: check that matching posts are published, label spelling is exact, and Full feeds are enabled.
  • No recent comments: use pixel-cmnt and confirm the public comment feed contains comments.
  • Page numbers are absent: use Older/Newer; Blogger may have shortened the page or the URL may not identify a known numbered page.
  • The XML will not save: paste the entire file and preserve Blogger tags, widget IDs, CDATA, and escaped ampersands.
  • Pages slow down after customization: check added images, ad scripts, embeds, and tracking gadgets individually.

For detailed instructions and current fixes, see the repository setup guide. Report reproducible theme bugs in GitHub Issues, including the affected URL, browser, expected behavior, and steps to reproduce.
