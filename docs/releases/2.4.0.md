# Pixel 2.4.0 — pagination, mobile, SEO, and accessibility

Released November 5, 2026.

Pixel is a free news and magazine Blogger template by Colorlib, built with vanilla JavaScript and distributed under GPL v3.

## Highlights

- **Reliable navigation:** correct menu nesting, encoded label links, and pagination that keeps Blogger's real Older/Newer links. Shortened pages, tied publication dates, failed requests, and stale responses no longer result in unsafe numbered jumps.
- **Complete responsive-page SEO:** article and breadcrumb JSON-LD in both post renderers, JSON-escaped values, canonical references, visible primary post headings, and no conflicting Open Graph fields.
- **Better phone layouts:** a usable search field, larger touch targets, stacked sidebars, wrapped titles/URLs, scrollable tables and code blocks, and responsive media.
- **Keyboard access:** a native search dialog with contained/restored focus, properly linked tabs with arrow/Home/End controls, and keyboard-operable gallery selectors.
- **Safer widgets:** escaped feed text, corrected empty-state images, a visible featured-feed error state, and gallery previews that follow the selected media, date, and permalink. Disqus loads only when its pane and a valid shortname are configured; new installs use native Blogger comments.
- **Documentation and checks:** installation, upgrade, customization, troubleshooting, and contributor guides; 40 regression tests, including offline Chrome layout and interaction checks.

## Download and install

Download `pixel-blogger-template.zip` from this release and extract it. Paste `Pixel-Blogger-Template.xml` into **Blogger → Theme → Edit HTML**. The XML is also attached separately; `SHA256SUMS` verifies both assets.

Back up your current theme and gadget settings first. Do not import the optional demo content to upgrade an existing blog. Match the theme's page size with Blogger's setting, then use the **Desktop** mobile option to serve the responsive theme.

## Validation and demo status

Both XML files and 23 standalone JavaScript blocks passed validation. All 40 regression tests passed, including five layout widths, phone/desktop pager interactions, and modeled JSON-LD branches. These fixtures do not replace Blogger's own rendering.

The hosted demo was updated to 2.4.0 on November 5, 2026, preserving existing widget settings, page URLs, and documentation comments. Live post output was checked for valid WebSite, BlogPosting, and BreadcrumbList JSON-LD. The documentation page and menu link were refreshed; native Blogger comments are the demo default. Existing sample-post copy remains a separate editorial cleanup.
