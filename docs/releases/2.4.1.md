# Pixel 2.4.1 — single pagination bar

Released November 5, 2026.

This patch fixes a pagination regression introduced in 2.4.0. The theme displayed an independent numbered pager above Blogger's native Older/Newer controls. On the hosted demo, duplicate publication timestamps caused numbered clicks to fail immediately.

- Optional page numbers now appear inside the existing pagination bar.
- Known duplicate/invalid dates select native navigation before offering numbered buttons.
- Failed or ambiguous later jumps remove the optional controls and preserve native links, without the previous dead-end message.
- First/last page targets are no longer repeated; single-page blogs receive no unnecessary page-number controls.

No post dates or published content need to change. Back up your theme, then install `Pixel-Blogger-Template.xml` from this release. Existing setup and upgrade instructions still apply.

Validation: XML and standalone JavaScript checks, 42 regression tests, and phone/desktop pagination DOM checks. The hosted demo uses native pagination for its duplicate-dated sample posts.
